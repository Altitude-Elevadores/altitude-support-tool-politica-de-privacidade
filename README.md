# Altitude Support Tool - Política de Privacidade

Este repositório hospeda a página de Política de Privacidade do aplicativo **Altitude Support Tool**.

A página está disponível em: [https://altitude-elevadores.github.io/altitude-support-tool-politica-de-privacidade/](https://altitude-elevadores.github.io/altitude-support-tool-politica-de-privacidade/)

## Objetivo
Informar aos usuários sobre o uso da câmera para chamadas de vídeo e a não coleta de dados indevidos, conforme exigido pelas diretrizes do Google Play Console.

## Como editar
1. Altere o arquivo `index.html` para modificar o texto.
2. Altere o arquivo `style.css` para ajustar o design.
3. Faça o commit e push para a branch `main`. O GitHub Pages atualizará o site automaticamente.
