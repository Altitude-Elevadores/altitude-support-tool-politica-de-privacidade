# Altitude Support Tool - Política de Privacidade

Página da Política de Privacidade do aplicativo **Altitude Support Tool** (equipe técnica), publicada pelo GitHub Pages:
[https://altitude-elevadores.github.io/altitude-support-tool-politica-de-privacidade/](https://altitude-elevadores.github.io/altitude-support-tool-politica-de-privacidade/)

O endereço está nas fichas da App Store e do Google Play. A seção "Como excluir sua conta" (`#excluir-conta`) é o link de exclusão de conta pedido pelo Google Play.

## Como editar
1. O texto fica em `index.html`; a data "Atualizada em" fica no topo e muda a cada alteração.
2. `style.css`, `logo.svg` e `fonts/` são iguais aos da política do app do cliente (`altitude-elevadores-app-privacy-policy`): mudou um, mude o outro.
3. Commit e push na branch `main`: o GitHub Pages atualiza o site sozinho.

Logo, cores e fontes seguem o Manual de Marca 1.0 (2026). Fontes Montserrat e Inter: SIL Open Font License.
